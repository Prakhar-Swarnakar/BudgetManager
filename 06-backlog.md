## Proposed, not yet decided

| Item | Notes |
|---|---|
| Duplicate detection | Flag two messages for the same payment (for example a bank alert and a UPI app confirmation) |
| Credit handling | Treat incoming money as refund, income, or ignored. In v1, credits are ignored |
| Learning from choices | Remember that a merchant maps to a category after the user confirms it once |
| Editable keyword rules | Let the user add or change keyword-to-category rules |
| Undo a rejection | Move a rejected message back to not assigned |
| Daily summary reminder | One gentle reminder such as "3 messages need review" |
